# Week 1 – Python Basics
## Personal Introduction Program

A beginner-friendly Python program developed as part of the Week 1 internship task at The Developers Arena.

The program collects basic information from the user and generates a personalized welcome message.

---

## Project Objectives

- Understand basic Python syntax and program execution.
- Practice variables and data storage.
- Use `input()` to collect user information.
- Use `print()` to display output.
- Work with strings and formatted strings.
- Develop and test a simple interactive Python program.

---

## Features

The program:

- Asks for the user's name.
- Asks for the user's age.
- Asks for the user's favorite hobby.
- Stores the responses in variables.
- Displays a personalized welcome message.
- Uses f-strings for formatted output.

---

## Technologies Used

- **Language:** Python 3
- **Libraries:** None
- **Environment:** VS Code / Python IDLE

No external Python packages are required.
