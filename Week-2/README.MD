# Week 2 – Student Grade Calculator

A Python-based Student Grade Calculator developed as part of Week 2 of the
Developers Arena internship task.

The program accepts a student's marks, validates the input, calculates the
corresponding grade, and displays an encouraging message.

---

## Project Objectives

- Implement decision-making using `if`, `elif`, and `else`.
- Implement repetition using loops.
- Use functions to organize reusable program logic.
- Validate user input.
- Calculate grades based on predefined mark ranges.
- Handle invalid input safely.
- Display an encouraging message for each grade.

---

## Grading Criteria

| Marks | Grade |
|---:|:---:|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 0–59 | F |

---

## Features

- Accepts marks from the user.
- Validates marks between 0 and 100.
- Handles non-numeric input.
- Handles marks outside the valid range.
- Calculates the student's grade.
- Provides an encouraging message.
- Uses functions for modularity.
- Uses a loop to repeatedly request valid input.

---

## Technologies Used

- Python 3
- Python Standard Library

No external packages are required.
